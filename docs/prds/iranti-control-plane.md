## Overview

The iranti control plane is the operational layer for managing iranti deployments — usage dashboards, fleet management, billing, and operational tooling for teams running iranti in production.

## What we know so far

- Deferred until iranti-core is stable and generating real usage data.
- Will integrate with usage analytics and cloud account features built in iranti-core (phases 7 and deferred).
- Likely a web dashboard combined with an admin API.
- The disconnect rate and active installation metrics from iranti-core's telemetry are the primary signals the control plane will surface.
