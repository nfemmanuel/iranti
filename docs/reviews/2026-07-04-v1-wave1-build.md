## 1. Headline

The default (heuristic, embedder-off) path is **byte-identical** to before — every one of these changes is either instrument-only, off-by-default, or a write-path guard, so nothing in a normal user's experience moved except that volatile junk stops being stored and a real corruption risk is closed.

## 4. The measurement (R0 vs R1) — read this before deciding anything about the LLM tier

Three regimes were planned. R0 (heuristic) and R1 (heuristic + local qwen2.5:7b via Ollama) ran; **R2 (frontier) is blocked** — no `bench/.env` key on disk (NF to provide).

**R1, three runs, identical every run:**

| Metric | R0 (heuristic) | R1 (+ local qwen2.5:7b) | Δ |
|---|---|---|---|
| extraction recall | 81.5% (44/54) | 81.5% (44/54) | 0.0 |
| extraction precision | 100% | 100% | 0.0 |
| fabricationRate | 61.9% | 61.9% | 0.0 |
| retrieval hit / confirmation | 85.7 / 67.9 | 85.7 / 67.9 | 0.0 |
| no-answer falsePositive | 60.0% | **30.0%** | **−30.0** |
| per-persona `stored` counts | ~13/11/14/8 | 13/12/14/8 | +0–1 |

**What this does and does NOT say:**

- **The LLM does no harm.** Zero new fabrications (including silence on all 8 trap sentences), no precision loss, no recall regression. That alone is a real result: an inventing model bolted onto the store did not degrade its honesty.
- **The LLM adds almost nothing *measurable here* — because the corpus is the finding.** The `stored` counts barely move: the four authored personas are written in clean `We decided to use X` / `Requirement: Y` shapes the heuristic already catches, so there is little conversational residue left for the LLM to extract. This is the OPPOSITE of the June A/B (real messy transcripts: regex 0, local LLM 133/50 msgs, 47/50). **The local LLM's advantage is on messy real conversation, and this corpus contains almost none.**
- **Two instrument limitations, both now the gating work for OD-2/AX-8:**
  1. **Scorer keys to heuristic key-shapes.** A gold fact is credited only if stored under the extractor's exact synthesized key. An LLM extracting the *same fact* under a differently-worded key earns zero credit. So recall structurally *cannot* rise on the LLM path even when it should.
  2. **Corpus realism ceiling.** Even with value-based credit, these clean sentences don't exercise the LLM's edge. A messy-transcript corpus (real Claude/Codex logs, like the June test) is required to measure the local-vs-frontier gap OD-2 deferred.
- **The falsePositive 60→30 improvement is real and replicated 3/3, but not yet mechanistically explained.** Likely the few LLM-added facts shift which facts win the per-entity cap on negative probes, displacing some that incidentally key-collided. Flagged for a trace, not spun as a win.

**Recommendation for the extraction-tier decision (unchanged direction, now evidenced):** do not judge local-vs-frontier on the authored corpus — it can't see the difference. Before AX-8 (cloud escalation) can be decided, the measurement needs (a) value-based scorer credit and (b) a messy real-transcript corpus. Until then, OD-2's "local default" stands, and the honest statement is "local does no harm on clean input; its value on messy input is untested by this instrument."
