that is meant to help across sessions, tools, and agents.

I am looking for people who already do real work with tools like Claude Code,

- use it across multiple sessions over a few days

- optionally do a short follow-up chat

The goal is not polished-demo feedback. I want honest signal on whether it is
actually useful and trustworthy in real workflows.

If you are interested, I will send:

- setup instructions

- the feedback form
- the beta time window
