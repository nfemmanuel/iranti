# Iranti Closed Beta Materials - v0.3.0

This folder holds draft materials for the `0.3.0` closed beta.

These are working docs, not final external-facing assets. They are meant to be
adapted into:

- Google Forms
- tester onboarding messages
- user-facing beta instructions
- internal recruitment notes

## Files

- `GOOGLE_FORM_DRAFT.md`
  Draft intake and post-test questions for async feedback collection.
- `TESTER_CHECKLIST.md`
  Practical user checklist for beta participants.
- `INVITE_MESSAGE.md`
  Draft invite copy for recruiting testers.
- `RECRUITMENT_GUIDANCE.md`
  Recommended tester mix and rationale for known vs unknown participants.

## Positioning

The `0.3.0` closed beta should validate continuity, not novelty.

The main question is:

> Does Iranti materially reduce rediscovery across sessions, hosts, and agent
> handoffs for real coding work?

## Notes

- Prefer small, high-signal cohorts over broad signups.
- Treat "TEST-COVERED" and "WORKING" as different things in all beta language.
- Keep host/setup limitations truthful.
