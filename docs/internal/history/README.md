# Internal History Index

This folder holds historical material that used to crowd the main docs surface.

These files are useful for audits, archaeology, and release forensics. They are not the current product contract.

## Historical Root Artifacts

- [Root Artifacts](./root-artifacts/)

This includes retired docs that previously lived at the top of `docs/`, such as audits, policy notes, hardening summaries, and local backlogs.

## Fix Verification Notes

- [Fix Verification](./fix-verification/)

These are dated verification notes for specific issue fixes and should be treated as historical evidence, not active operator guidance.

## Validation Execution Notes

- [Validation Execution](./validation/)

These are dated execution logs and validation run transcripts. They are useful when you need to confirm what was actually run on a given date, but they are not the current release gate or product contract.
