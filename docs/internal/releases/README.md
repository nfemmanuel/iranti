# Release Artifacts

This folder stores historical release-readiness and stabilization ledgers.

These files are supporting evidence, not canonical product docs.

Use canonical docs first:
- `docs/guides/` for operator and developer workflows
- `docs/features/*/spec.md` for behavior and edge cases
- `docs/operations/` for deployment and troubleshooting
- `docs/decisions/` for architectural decisions

## Release Cycles

- [`0.2.26/`](./0.2.26/) - final `0.2.x` stabilization hardening and release execution artifacts

## Rule Of Thumb

If a release artifact disagrees with a guide, feature spec, operations doc, or decision record, prefer the canonical doc.
